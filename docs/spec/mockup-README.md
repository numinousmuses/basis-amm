# Basis-AMM UI Mockups

Open `index.html` in a modern browser. All ten pages are included in this one self-contained HTML file: market discovery, trading, positions, portfolio, liquidity vault, public protocol statistics, activity, risk monitor, admin console, and settings.

The screens use illustrative data only. Buttons and configuration controls are for interactive design review; they do not connect to NEAR or place trades.

Read `Basis_AMM_Engineering_Spec_v0.1.md` for the detailed architecture and economic model. Despite its historical filename, the included file is the updated specification with uncapped profits relative to margin and no mandatory +100% auto-close.
